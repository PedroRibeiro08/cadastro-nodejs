# Sistema de Cadastro

Projeto simples feito com Node.js, Express e EJS.

## Como executar

Abra o terminal na pasta do projeto e rode:

npm install

Depois:

npm start

Acesse:

http://localhost:3000

## Estrutura

O projeto possui cadastro de categorias, clientes, fornecedores e produtos.

Os registros ficam salvos em arquivos JSON dentro da pasta data.
